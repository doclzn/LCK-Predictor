LCK PREDICTOR V10.1 — CORREÇÃO DO RUNTIME PORTÁTIL

Problema corrigido:
ModuleNotFoundError: No module named 'riot_feed'

Causa:
O runtime embutido oficial do Python para Windows usa um arquivo ._pth que
restringe os caminhos de importação. Em algumas máquinas, a pasta do server.py
não entra automaticamente no sys.path.

Correções:
1. server.py adiciona explicitamente a própria pasta ao sys.path antes de importar riot_feed.
2. ABRIR_LCK_PREDICTOR.bat verifica server.py, riot_feed.py e o banco antes de iniciar.
3. TESTAR_INSTALACAO.bat foi incluído para diagnóstico rápido.

Recomendação:
Extraia ESTE ZIP em uma pasta NOVA. Não copie apenas server.py por cima da V10 antiga.
O runtime já baixado na pasta antiga não é necessário; a nova pasta baixa o mesmo
runtime oficial de ~11 MB na primeira execução.
