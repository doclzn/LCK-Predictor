LCK PREDICTOR V5 — DRAFT INTELLIGENCE REVIEW
================================================

Dataset used for validation:
- 900 LCK games total in local draft dataset
- 2025 = training/development
- 2026 through 2026-06-14 = untouched future holdout

Baseline Elo:
Accuracy 0.676
Log Loss 0.600
Brier 0.207
AUC 0.734

PASS 1 — Full feature draft model
Features: meta + player mastery + counters + synergy + coverage + Elo
Accuracy 0.691
Log Loss 0.604
Brier 0.207
AUC 0.730
Review: rejected as production core. Accuracy improved, but probability quality and discrimination did not.

PASS 2 — Simplified core
Features: Elo + player×champion mastery + champion-pair synergy
Accuracy 0.676
Log Loss 0.597
Brier 0.205
AUC 0.737
Review: retained. Better calibrated than baseline/full draft model.

PASS 3 — Temporal regularization tuning
Selected C=0.03 using chronological 2025 development validation only.
Final untouched 2026:
Accuracy 0.688
Log Loss 0.595
Brier 0.204
AUC 0.738

Decision:
The predictive core uses Elo + player/champion mastery + pair synergy.
Champion meta and lane counters are DISPLAYED as contextual evidence but are not weighted in production probability yet.

Important limitations:
- Detailed player/champion LCK data cutoff: 2026-06-14.
- Current LCK results/Elo cutoff: 2026-08-19.
- Local career history begins in 2025; full player career is not yet ingested.
- LPL and LCK Challengers feeds are identified but intentionally not mixed into the model yet.
- Draft output is a GAME probability; pre-series probability remains a separate quantity.
