# V22 — UX Refresh

## Objetivo
Melhorar legibilidade e usabilidade sem mudar o núcleo estatístico.

## Mudanças
- Base tipográfica aumentada.
- Match cards com hit area maior.
- Hero e painéis com respiro maior.
- Quick Start na Home.
- Botão flutuante “Como usar”.
- Modal com passo a passo para acompanhar partidas.
- Ícones locais para os times da LCK (badges SVG com siglas).

## Observação
Esta versão foca experiência do usuário. O modelo preditivo permanece o mesmo da V21.
