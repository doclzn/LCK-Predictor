Rules:

- The UI always shows patch analytics even when a patch feature does not earn predictive weight.

EXECUTION REVIEW
----------------
A review found that the promoted patch model had initially been stored/validated but not yet wired into the live central score.
This was corrected.

Runtime rule:
- selected patch + exact local patch evidence -> V7 patch-aware score;
- new/unconfirmed patch with no exact local evidence -> automatic V6 fallback;
- UI explicitly labels which mode is active.

This prevents a new patch from inheriting fake certainty from an older patch.
