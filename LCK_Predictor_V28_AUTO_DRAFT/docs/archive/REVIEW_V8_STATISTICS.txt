LCK PREDICTOR V8 — STATISTICAL RE-AUDIT
===========================================

WHY THIS VERSION EXISTS
-----------------------
Earlier V6/V7 development compared some hyperparameters / feature families on the 2026 holdout
before finalizing them. Those metrics were useful exploratory estimates, but not a fully untouched test.

V8 resets the methodology:
1. ALL feature and hyperparameter selection is performed only with rolling-origin 2025 windows.
2. 2026 is opened once, after the model is frozen.
3. Uncertainty is bootstrapped by SERIES, not by pretending each game is independent.

PASS 1 — MODEL-SELECTION AUDIT
------------------------------
2025 rolling-origin selected:
- player×champion Empirical-Bayes prior strength: 32 equivalent games
- champion-pair synergy prior: Beta(2,2)
- C: 0.10

Best 2025-CV feature candidate included exact-patch champion meta.

PASS 3 — UNCERTAINTY / CALIBRATION
----------------------------------
V8 calibration slope: 0.9755 (ideal ~1)
V8 calibration intercept: 0.0027 (ideal ~0)
10-bin ECE: 0.0323

Series-cluster 95% bootstrap intervals:
Accuracy: 0.6401 — 0.7449
Log Loss: 0.5417 — 0.6389
Brier: 0.1812 — 0.2242
AUC: 0.6803 — 0.7951

Paired V8 - Elo 95% intervals:
Accuracy delta: -0.0028 — 0.0342
Log Loss delta: -0.0135 — 0.0001
Brier delta: -0.0054 — 0.0001
AUC delta: -0.0035 — 0.0123

INTERPRETATION
--------------
V8 is slightly better than Elo on the point estimates, especially accuracy and probabilistic scores.
However, the paired bootstrap intervals for the metric improvement touch/cross zero.
Therefore the added draft features are promising, but the current sample does NOT justify claiming
a statistically decisive improvement over Elo.
