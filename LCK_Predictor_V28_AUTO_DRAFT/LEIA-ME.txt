LCK PREDICTOR V21 — MODEL GOVERNANCE

ABRIR O APP
1. Extraia o ZIP inteiro em uma pasta nova.
2. Execute ABRIR_LCK_PREDICTOR.bat.
3. Na primeira execução, o launcher baixa o runtime portátil oficial do Python.

O QUE A V21 MUDA

A V21 não tenta aumentar a accuracy com mais uma heurística.
Ela cria um lockbox para que os próximos testes realmente sejam prospectivos.

1. V19 CANDIDATES CONGELADAS POR HASH
   - core
   - core + pool exhaustion
   - core + remaining pool
   - core + flex
   - core + exhaustion + flex

   Alterar coeficiente, feature list, scaler ou modelo durante o mesmo epoch
   gera drift de integridade e bloqueia a candidata.

2. PROSPECTIVE CAPTURE LEDGER
   Cada nova previsão válida recebe:
   - experiment ID;
   - model definition hash;
   - feature hash;
   - timestamp;
   - game ID;
   - capture status.

3. GATE DE PROMOÇÃO PRÉ-REGISTRADO
   Mínimo:
   - 100 mapas futuros;
   - 40 séries futuras;
   - captura até 5 min;
   - Δ Log Loss <= -0.005;
   - Δ Brier <= -0.002;
   - ambos IC95% bootstrap com upper bound <= 0;
   - ECE no máximo +0.01 pior que o core.

   Mesmo passando tudo, o resultado é apenas:
       ELIGIBLE_FOR_REVIEW
   Nunca existe promoção automática para Production.

4. LIVE MODEL V1 PRÉ-REGISTRADO
   O protocolo foi congelado ANTES de haver dataset suficiente.

   - 120 mapas mínimos;
   - 8 times;
   - checkpoints 5/10/15/20/25/30 min;
   - split cronológico 65/15/20 por MAPA;
   - snapshots do mesmo mapa nunca atravessam splits;
   - seleção de família e C apenas no validation set;
   - test set abre uma única vez por protocol ID;
   - segunda tentativa de retuning é recusada.

5. TREINO PORTÁTIL
   Quando o gate estiver pronto:
       TREINAR_LIVE_QUANDO_PRONTO.bat

   Até lá, o script encerra sem ajustar qualquer modelo.
