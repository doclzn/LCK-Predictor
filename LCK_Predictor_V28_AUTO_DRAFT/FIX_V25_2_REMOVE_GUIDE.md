# V25.2 — Guia removido

O componente "Guia de Uso" foi removido integralmente.

Removidos:
- botão "Ver passo a passo";
- botão flutuante "Como usar";
- modal/overlay;
- handlers de abrir/fechar;
- inicialização automática do componente.

Também foi incluída uma regra CSS defensiva para esconder qualquer resíduo do componente caso exista HTML antigo em cache.
